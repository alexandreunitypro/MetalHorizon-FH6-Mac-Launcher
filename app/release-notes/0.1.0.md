**Prototype. Not for players yet.** First build of the MetalHorizon launcher for Forza Horizon 6, Xbox / Microsoft Store edition, on Apple silicon Macs.

### What works
- **Sign in with Microsoft** on Microsoft's own page. The session is kept in the macOS Keychain; MetalHorizon never sees your password.
- **Download from Xbox**: from the official servers, only if your account owns the game.
- **Play**: starts the game with the same settings as `tools/jouer.sh` (cloud saves, engine sound, online matchmaking as of 25 October 2026).

### What it still needs
- The MetalHorizon Wine engine, built from [`engine/`](https://github.com/alexandreunitypro/FORZA-LAUNCHER-FOR-MAC-BLACKWELL-PROJECT/tree/main/engine). A downloadable engine comes next.
- CrossOver.app installed (its d3d12 bridge and libraries are still used).
- D3DMetal 4 from Apple's Game Porting Toolkit 4, picked in the app. It is Apple's and is not included.

Known: frame pacing (about 6 freezes of 175–300 ms every 25 s), black near foliage. See the README.

### Install
1. Unzip `MetalHorizon-0.1.0.zip` and move **MetalHorizon** to Applications.
2. The app is not notarized yet: the first time, right-click it → **Open** → **Open**.
3. If macOS asks to let `xodus-service` use the "Xodus Service" Keychain item, choose **Always Allow**.

### Files
- `MetalHorizon-0.1.0.zip`: the app (ad-hoc signed, arm64).
- `xodus-source-0.1.0.tar.gz`: GPL-3.0 source of the two bundled [xodus](https://github.com/xodus-gaming/xodus) binaries.
- `SHA256SUMS`
