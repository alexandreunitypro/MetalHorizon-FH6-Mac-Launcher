**Prototype. Not for players yet.** MetalHorizon launcher for Forza Horizon 6, Xbox / Microsoft Store edition, on Apple silicon Macs.

### New in 0.2.0
- **AI assistant (MCP).** MetalHorizon is also an MCP server (`MetalHorizon --mcp`). Connect Claude Code, Claude Desktop or another MCP app (*AI Assistant…* in the app shows the lines to copy) and the assistant can check your setup, read the logs with tokens removed, explain errors, find the engine and D3DMetal 4 on your Mac and change the settings with you. It never sees your password and cannot start the game or a download.
- **A plain macOS window**: standard title bar, grouped boxes, system status lights, light or dark like the system.

### What works
- **Sign in with Microsoft** on Microsoft's own page. The session is kept in the macOS Keychain; MetalHorizon never sees your password.
- **Download from Xbox**: from the official servers, only if your account owns the game.
- **Play**: starts the game with the same settings as `tools/jouer.sh`.

### What it still needs
- The MetalHorizon Wine engine, built from [`engine/`](https://github.com/alexandreunitypro/FORZA-LAUNCHER-FOR-MAC-BLACKWELL-PROJECT/tree/main/engine).
- CrossOver.app installed (its d3d12 bridge and libraries are still used).
- D3DMetal 4 from Apple's Game Porting Toolkit 4, picked in the app. It is Apple's and is not included.

### Install
1. Unzip `MetalHorizon-0.2.0.zip` and move **MetalHorizon** to Applications.
2. Not notarized yet: the first time, right-click it → **Open** → **Open**.
3. If macOS asks to let `xodus-service` use the "Xodus Service" Keychain item, choose **Always Allow**.
