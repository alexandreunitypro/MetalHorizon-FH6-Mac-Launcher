**Prototype.** MetalHorizon for Forza Horizon 6, Xbox / Microsoft Store edition, on Apple silicon Macs.

### New in 0.3.1
- **A welcome window** on first launch: what MetalHorizon does by itself and the few steps that are yours.
- **☕ Support Me**: opens [buymeacoffee.com/zaidalexandre](https://buymeacoffee.com/zaidalexandre).

### From 0.3.0
- **No CrossOver.app any more.** The game runs on **Blackwell Engine**, MetalHorizon's own Wine, with Apple's D3DMetal 4.
- **Everything installs by itself.** On first launch the app downloads Blackwell Engine and Apple's D3DMetal from [blackwell-engine](https://github.com/alexandreunitypro/blackwell-engine/releases), checks their SHA-256, shows Apple's licence (D3DMetal installs only if you accept it) and sets up the DirectX 12 shim.
- AI assistant (MCP), plain macOS window (from 0.2).

### Get started
1. Unzip `MetalHorizon-0.3.1.zip` and move **MetalHorizon** to Applications.
2. Not notarized yet: the first time, right-click it → **Open** → **Open**.
3. Accept Apple's licence when asked, then **Sign In with Microsoft…**.
4. Choose a game folder with a short path (for example `~/FH6`, not in iCloud Drive), click **Download from Xbox** (about 160 GB), then **Play**.
5. If macOS asks to let `xodus-service` use the "Xodus Service" Keychain item, choose **Always Allow**.

Quit the game from its own menu and wait about 30 seconds: the cloud save uploads as it closes.

### Known
Frame pacing (short freezes), black near foliage, a crash while the map loads under heavy logging. Tested on one Mac (M5 Pro, 48 GB, macOS 27).
