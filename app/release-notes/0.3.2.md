**Prototype.** MetalHorizon for Forza Horizon 6, on Apple silicon Macs.

### New in 0.3.2
- **Experimental Steam support.** Point the game folder at your Steam install of Forza Horizon 6 (Steam
  installs ship `steam_appid.txt`) and MetalHorizon installs a second engine — Blackwell Engine's own series
  plus two of [Highball](https://github.com/gauthierpiarrette/highball-engine)'s own patches, so a launcher's
  own window (Steam's included) draws instead of staying black — then downloads and installs Steam itself into
  a prefix of its own, and plays through Steam (`steam.exe -applaunch`), so the Steam client stays resident as
  Forza Horizon 6 on Steam expects. **Not verified in game: this project has no Steam copy to test with.**
  Signing in and installing the game in Steam's own window is your step, like Microsoft sign-in already is for
  the Xbox edition. Please report back if you try it.

### From 0.3.1
- A welcome window on first launch, and **☕ Support Me** ([buymeacoffee.com/zaidalexandre](https://buymeacoffee.com/zaidalexandre)).
- No CrossOver.app: the game runs on **Blackwell Engine**, MetalHorizon's own Wine, with Apple's D3DMetal 4.
- Everything installs by itself from [blackwell-engine](https://github.com/alexandreunitypro/blackwell-engine/releases), checked by SHA-256.

### Get started (Xbox / Microsoft Store edition)
1. Unzip `MetalHorizon-0.3.2.zip` and move **MetalHorizon** to Applications.
2. Not notarized yet: the first time, right-click it → **Open** → **Open**.
3. Accept Apple's licence when asked, then **Sign In with Microsoft…**.
4. Choose a game folder with a short path (for example `~/FH6`, not in iCloud Drive), click **Download from Xbox** (about 160 GB), then **Play**.
5. If macOS asks to let `xodus-service` use the "Xodus Service" Keychain item, choose **Always Allow**.

### Get started (Steam edition, experimental)
1. Point the game folder at your Steam install of Forza Horizon 6.
2. Click **Install Steam…** next to "Steam client", click through Steam's own installer, then sign in.
3. Click **Play**: MetalHorizon launches Forza Horizon 6 through Steam.

Quit the game from its own menu; for the Xbox edition, wait about 30 seconds so the cloud save uploads.

### Known
Frame pacing (short freezes), black near foliage, a crash while the map loads under heavy logging (Xbox
edition). Steam edition: untested beyond installation. Tested on one Mac (M5 Pro, 48 GB, macOS 27).
