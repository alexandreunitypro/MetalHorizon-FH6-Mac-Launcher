**Early alpha.** A fix for the Steam edition, from the first reports on 0.4.0. MetalHorizon 0.4.0 updates itself to this version when it opens.

### Steam edition: Play no longer crashes Steam
- **The crash**: on macOS 27, the silent Steam client that starts the game inherited D3DMetal for its own web views and aborted (`-[NSViewBackingLayer setDisplaySyncEnabled:]: unrecognized selector`) before the game started. Reproduced on an M5 Pro with macOS 27.2.
- **The fix**: that client's web views now run without the GPU (`-cef-disable-gpu`); only the game gets D3DMetal. Checked on the same Mac: no abort, Steam and its web helpers keep running.
- **A second way, automatic**: if Steam still cannot start the game (the client stops, or nothing happens for 5 minutes after you have signed in once), MetalHorizon keeps Steam running beside the game on DXMT and starts the game itself with D3DMetal, telling it which Steam game it is (`SteamAppId`) so it gets its Steam ticket. The way that worked is remembered for the next Play.
- Clearer messages while waiting, and no stray "Terminated: 15" line when Steam stops.

### Still true
- The Steam edition is not tested in game here (no Steam copy). If Play does not work, the crash report MetalHorizon offers has everything needed.
- You need your own copy of the game, bought on Steam or the Microsoft Store.
