**Early alpha.** A new MetalHorizon: one window, one button. MetalHorizon 0.4 updates itself to this version when it opens; your settings, sign-in, engines and game are kept.

### One button that always does the next step
The setup form is gone. The window shows the game, the road to Play and one big button that does whatever comes next:
- **Xbox / Microsoft Store**: Install the Engine, Sign In with Microsoft, Download the Game, then **Play**.
- **Steam**: Install the Engine, Install Steam, Open Steam (sign in and install the game there), then **Play**.

Right after you sign in with Microsoft, the game's download starts by itself when the disk has room for it (about 170 GB); otherwise the window says how much is free. A line under the button says what it will do, or what is happening right now. Stop and Force Quit sit beside it while something runs.

### The road to Play
Four stops on one line (Engine, Account or Steam, Game or Library, Play): what is done is filled, the next step is ringed. You can see where you are at a glance, and what is left.

### Your copy, found by itself
An Xbox copy already on this Mac is found without a folder dialog: in `~/FH6`, `~/Games`, the Desktop or Documents, or on an external disk (`/Volumes/<disk>/FH6`, `/Volumes/<disk>/Games/FH6`). Reinstalling MetalHorizon, or moving to a new Mac with the game on an external SSD, goes straight to Play.

### Out of the way until you need it
- **What needs attention** appears under the button only when there is something to fix, each item with its fix in plain words.
- **The activity log** moves to a side panel: the Activity button in the toolbar opens it, with Errors only, search, the game's own output and Export Diagnostics.
- **Settings** (MetalHorizon › Settings, Cmd-,): General (edition, game folder, Steam's space, the components, the Xbox account), Graphics (Metal HUD, MetalFX, frame cap), Controllers (the pads connected, how each one reaches the game, Wine's test panel) and Advanced.
- **The edition** is a switch in the toolbar.
- **First launch**: a short welcome that asks which copy you own, then gets out of the way.

### Design
A Mac window in the system's own type and controls, light and dark, in one deep horizon blue. On macOS 26 and later it is built in Liquid Glass: the Play button, the road to Play, the panels and the welcome are glass over a blue horizon, and the toolbar and the Activity panel are the system's own glass. Earlier macOS versions get the same layout in solid colour. Motion follows Reduce Motion.

### Unchanged
Everything that runs underneath: Blackwell Engine 1.1, D3DMetal 4, the Steam fix of 0.4.1, the automatic diagnosis, crash reports, controllers, the MCP server and the automatic updates.
