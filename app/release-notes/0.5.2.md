**Early alpha.** A patch for E:0-0-L-8, and graphite everywhere. MetalHorizon 0.4 and 0.5 update themselves to this version when they open.

### E:0-0-L-8 (the game asks you to sign in, then fails)
- The game shows this when it starts without receiving its account. On Steam, it can happen when MetalHorizon starts the game beside Steam (the second way, used when Steam could not start it): if a run that way ends in E:0-0-L-8, MetalHorizon no longer keeps it, and the next Play lets Steam start the game again, which hands it its ticket.
- The diagnosis now covers both editions and says what to do. If it stays, Activity › Export Diagnostics gives everything needed for an issue.

### Graphite everywhere
- The last blue is gone: the buttons of the crash report, Apple's licence, the update and the AI assistant windows, the Settings window and the progress bars now use the same graphite as the main window.

- `MetalHorizon-0.5.2.zip`: the app (ad-hoc signed, arm64). Same engines as 0.4 and 0.5 (blackwell-engine-1.1).
