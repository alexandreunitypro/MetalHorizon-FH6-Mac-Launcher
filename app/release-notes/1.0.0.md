**1.0 Final Beta.** The biggest MetalHorizon yet: a second engine that runs natively on Apple silicon and removes the hitch every second, and an Autopilot that checks, repairs and reconfigures by itself. MetalHorizon 0.4 and 0.5 update themselves to this version when they open.

### No more hitch every second: Blackwell Engine Native
Under Rosetta, Forza Horizon 6 stops for about a tenth of a second roughly once a second: its copy protection keeps rewriting its own code, and Rosetta translates that code again each time. **Blackwell Engine Native** runs the game natively on Apple silicon instead, through FEX with Highball's patches that keep those translations, and draws through vkd3d-proton on KosmicKrisp (Mesa's Vulkan on Metal 4). The result, measured by Highball on a base M4 at 1080p: **a steady 30 frames a second with no hitch over 150 ms**, where D3DMetal reaches up to 50 with the hitch.
- **Built for the Xbox / Microsoft Store edition**: Wine 11.18 for arm64 with Highball's arm64 patches and MetalHorizon's Xbox patches ported to it (the Xbox game runtime, protected packages, app packages, network, audio, GameInput). xodus signs in, checks the licence and maps the protected files exactly as before.
- **Automatic**: on a Mac with Apple silicon, macOS 27 and 24 GB of memory or more, MetalHorizon installs it by itself and uses it. Elsewhere, or if it fails, D3DMetal runs the game as before. Settings › Graphics › Engine: Automatic, Native Apple silicon, or D3DMetal.
- **Its own Wine prefix**, so the D3DMetal setup stays exactly as it was. The first start takes about 10 minutes (the game's Optimizing for your PC), once. The game then starts at 1080p, Very Low, FSR Quality, capped at 30: the settings it was measured on. Change them in the game; a frame cap in Settings › Graphics replaces the 30.
- **The signed loader**: a native Wine needs Apple's cross-architecture entitlement, which only a signed app can carry. MetalHorizon takes Highball's signed `WineLoader.app` from Highball's official release and refuses it unless its signature is Highball's Developer ID team. Thank you, Gauthier Piarrette and Highball's contributors: this engine stands on their native route.

### PC Game Pass
- **Say you play through Game Pass** when MetalHorizon first opens (or in Settings › General): PC Game Pass and Game Pass Ultimate run the same Xbox copy, and Microsoft's licence server hands it a lease at every start, exactly as the Xbox app does. Nothing is bypassed: an account whose plan does not include the game gets no licence.
- **Game Pass's own problems are handled**: a plan that ended or does not include PC games (Microsoft's "not entitled" answer) is recognized and explained, with a button to the account's subscriptions page; MetalHorizon asks for the licence again at the next Play. A lease needs the internet at every start: Play checks Microsoft's licence server first and waits up to a minute for the network instead of failing.

### The Doctor: the app repairs itself
MetalHorizon now carries a catalogue of more than forty known problems, each with how it shows and the treatments to try, cheapest first. It looks when the app opens, every quarter of an hour while idle, before every Play, after every run and after a failed sign-in, download or Steam step, and reads only what it can check by itself: the last runs' logs and exit codes, the components on disk, the Xbox service, the network and the clock, the disk, the app's own location.
- **Automatic** when it is safe: a damaged engine, D3DMetal or native engine reinstalled; the DirectX 12 shim reassembled; the native loader relinked or taken again from Highball's release; quarantine and lost permissions repaired; a stuck or crashing Xbox service restarted; a moved game folder found again; a missing game package put back; shader caches rebuilt after a lost device; an old Wine server stopped; the Wine prefix's system files rebuilt (saves untouched); a frame cap after macOS stopped the game for memory; the native engine taking over when Rosetta is missing or D3DMetal keeps failing on the Neural Engine or the graphics card; MetalHorizon's own leftovers cleared when the disk is almost full.
- **One click** when it touches something of yours: move the game out of an iCloud folder or a too-long path (one rename on the same disk), move MetalHorizon out of App Translocation, install Rosetta (macOS asks for your password), quit Steam for macOS, open your Microsoft subscriptions, unlock the Keychain, fix the clock or the network, resume an interrupted download.
- **A budget for every treatment**: one that did not cure the problem is not tried again in a loop; the next one is, and after the last the window explains.
- **Under "MetalHorizon can fix this"** the one-click fixes wait with their button; under **"Fixed by MetalHorizon"** everything done is listed. All of it is in the logs and in Export Diagnostics.

### The Autopilot: problems fixed before you see them
- **Before every Play** it repairs what it can without touching your data: the native engine's loader link, an Xbox service that runs without its socket, a Wine server left over from a crash.
- **After every run** it reads what happened. A game that stops in the first minutes is **started again once, by itself**. An engine that stops the game twice in a day is **set aside for three days** and the other engine runs the game. MetalFX upscaling that crashed a run is turned off; an msync failure switches to Wine's plain synchronization; a graphics card refusal (FH205/FHE21) rebuilds the DirectX 12 shim.
- **Everything it does is shown** under **Fixed by MetalHorizon** in the window, kept in the logs and in Export Diagnostics, and every setting it changed can be changed back in Settings.
- **It never touches**: your saves, the game's files, your sign-in. A profile or account problem (E:43-1b-4, E:0-0-L-8) is explained, never "fixed" by switching engines.

### Fixes
- **The Keychain window that blocked Play**: after a new Microsoft sign-in, macOS asked "xodus-cli wants to use your confidential information" and the game waited behind that window, often hidden. Play and the download now run through the same xodus program that signed you in, which the Keychain already trusts; if macOS still asks, the window under the Play button says so.
- **A cancelled Keychain window is recognized**: xodus stopped at once (exit 101) with no explanation when macOS's Keychain window was answered Cancel; the window now says to press Play and choose Always Allow.
- **"The download needs about 160 GB" for an installed game**: checks run in parallel at launch, and one started before the game folder was known could finish last. Only the newest round counts now.
- **A run's problems shown under the other edition**: the window shows the last run of the edition you are on.
- **A licence request that never answers no longer hangs Play**: after 45 s without an answer the window says to check the network; after 3 minutes the request is stopped, the Xbox service restarted and the game tried once more, by itself.
- **Downloads retry**: GitHub's release host answers 502 or 504 for minutes at a time; components are now fetched again up to five times, waiting longer each time.
- **Updates never land under a running game**: the update waits for the game, even one started by an earlier MetalHorizon.
- **A signed component is never modified**: its install record is kept beside it, not inside it.

### Known
- **Tested on one Mac** (M5 Pro, 48 GB, macOS 27.2) with the Xbox edition: on the native engine the game passes its licence check, maps its protected files, renders through vkd3d-proton on KosmicKrisp and plays its sound, up to its own screens. A full drive was not measured here yet (the test account's Forza profile answers E:43-1b-4); the frame-time figures are Highball's, on a base M4. Please report how it runs on yours: Activity › Export Diagnostics has everything needed.
- **The Steam edition stays on D3DMetal** in this version: the native engine needs a Wine prefix of its own, and Steam would download the game again into it.
- The native engine runs at 30 frames a second by design (steady rather than fast); Highball notes a few seconds of stalls about half a minute into the first drive of a session.
