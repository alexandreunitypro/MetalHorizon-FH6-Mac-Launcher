**Fixes for the Steam edition and for downloads**, from issues #10, #11 and #12. MetalHorizon updates itself to this version when it opens.

### Steam: the game no longer closes after about two minutes
- **Steam starts the game every time.** When Steam could not start the game once, MetalHorizon started it itself beside Steam, and it *remembered* that way: every later Play then ran the game without its Steam ticket, and the game closed after about two minutes (issues #11 and #12). Now Steam always starts it; the second way is only a fallback for the same Play, never kept, and if the game closes early that way MetalHorizon says so and what to check.
- **No more relaunch loops on the Neural Engine message.** D3DMetal's Neural Engine abort happens in the first seconds; past 30 s its line is only a harmless message every start prints. MetalHorizon relaunched the game on it after 117 s, which hid the real cause. Only an abort in the first 30 seconds is relaunched now (Steam and Xbox editions).

### Downloads that GitHub refuses (issue #10)
GitHub's release host can answer 504 for minutes. After five tries with growing waits, MetalHorizon now tries once more through macOS's own downloader, which resumes where it stopped and retries on its own.
