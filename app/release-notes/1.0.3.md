**Fixes from issues #14 and #16.** MetalHorizon updates itself to this version when it opens, and installs the fixed native engine by itself.

### Xbox and Game Pass: "Game Crash, FHE01" on the native engine (issue #14)
- **The cause**: on Blackwell Engine Native 1.0 the game called a function of Microsoft's C++ concurrency library (`concrt140`'s concurrent queue iterator) that the native engine's Wine did not have. The game stopped at its title screen with its own window: Game Crash, FHE01.
- **The fix**: **Blackwell Engine Native 1.1** has that code (the same as in the Rosetta engine, where the game already ran). MetalHorizon downloads it by itself at the next launch.
- **A crash is seen as a crash now**: Wine's debugger and the game's crash window end with exit code 0, so MetalHorizon saw five crashes in a row as normal exits and did nothing. It now reads the crash in the log: the game is started again once, and after two crashes in a day the other engine (D3DMetal) runs it, without you having to choose.

### Steam: when Steam does not start the game (issue #16)
- When the silent Steam client stops before starting the game, MetalHorizon now writes what Steam said into the run's log (it used to say only "the Steam client stopped") and tries Steam **once more from a clean start** before anything else. Starting the game beside Steam stays the last resort, because the game gets no Steam ticket that way (E:0-0-L-8).
- If you still get E:0-0-L-8 on this version, please send the zip from Activity › Export Diagnostics: it now carries Steam's own last lines.

### Known
- **PS5 (DualSense) controller seen but not working in the game** (issue #15): not fixed in this version. The pad reaches Wine (its test panel shows it) but not the game's GameInput. Under investigation; a wired Xbox-layout pad is the safest for now.
