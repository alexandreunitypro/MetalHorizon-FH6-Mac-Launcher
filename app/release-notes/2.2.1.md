**MetalHorizon X 2.2.1: the Steam edition's Xbox sign-in, fixed for real ("Sign In Required", issue #21).** MetalHorizon updates itself to this version when it opens.

### Steam edition: Xbox sign-in
- 2.2.0 let the game's own Xbox runtime load, but hid the game's identity from it. The runtime then could not read the game's settings, and the game still showed "Sign In Required".
- The game now keeps its identity. The first time, it shows a code: enter it at microsoft.com/link with your Microsoft account. The game keeps the sign-in after that.
- A Steam client started by 2.2.0 is restarted once before the game starts, so that the game gets the new settings.
- Measured with Microsoft's own Xbox runtime (`xgameruntime.dll`, GDK 2610) on Blackwell Engine steam-1.4:
  - with the identity, the runtime starts and reaches Microsoft's sign-in prompt;
  - with 2.2.0's settings it stops with E_GAMERUNTIME_GAMECONFIG_BAD_FORMAT;
  - with 2.1.2's it stops with E_GAMERUNTIME_DLL_NOT_FOUND.
- This was checked with a stand-in Steam and game, not yet with the real Steam copy. If the sign-in still fails, Activity › Export Diagnostics right after the message shows where it stops.

Everything else is as in 2.2.0. Reports still open a GitHub issue until the developer's report server has its address.
