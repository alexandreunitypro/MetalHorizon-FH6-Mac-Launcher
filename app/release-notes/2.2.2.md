**MetalHorizon X 2.2.2: the Steam edition records its Xbox sign-in, to find why it still says "Sign In Required" (issue #21).** MetalHorizon updates itself to this version when it opens.

### Steam edition: the Xbox sign-in, recorded
- Since 2.2.1 the game shows Microsoft's sign-in code, but after the code some players still get "Sign In Required". Without a Steam copy of the game, the step that fails cannot be seen here.
- The game log now records each request of the game's Xbox sign-in: the address, Microsoft's answer and its error code. No token, password or account is kept.
- If the sign-in fails for you: try once, then click Activity › Export Diagnostics and attach the zip to issue #21. That shows which request fails, and the fix follows.
- A Steam client started by 2.2.1 is restarted once before the game starts.

Everything else is as in 2.2.1.

- `MetalHorizon-2.2.2.zip`: the app (ad-hoc signed, arm64).
- `xodus-source-2.2.2.tar.gz`, `SHA256SUMS`
