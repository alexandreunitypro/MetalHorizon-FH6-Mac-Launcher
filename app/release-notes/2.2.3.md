**MetalHorizon X 2.2.3: the Steam edition runs as on a Windows PC, past "Initialization Failed" (E:0-0-L-8, issue #21).** MetalHorizon updates itself to this version when it opens, and installs Blackwell Engine 1.4.1 by itself.

### Steam edition
- With 2.2.2, the Xbox sign-in worked to the end (a player's diagnostics showed all 47 sign-in and online requests answered), then the game stopped with E:0-0-L-8. It carried the Microsoft Store copy's identity, which a Steam game never has on a Windows PC.
- The game now has no package identity, as on Windows and in Highball's engine: its own Xbox runtime reads the game's settings by itself. This needed an engine fix: Blackwell Engine 1.4.1 answers "no package" the way Windows does. Before it, Microsoft's runtime refused to start without the identity.
- Checked with Microsoft's own runtime (`xgameruntime.dll`, GDK 2610): it starts without the identity on 1.4.1, as on Highball's engine, and not on 1.4. Not yet checked with the real Steam copy of the game.
- The first time, the game shows a code to enter at microsoft.com/link. The game log still records the Xbox sign-in's requests (no token or account) for Export Diagnostics.
- A Steam client started by an older MetalHorizon is restarted once.
